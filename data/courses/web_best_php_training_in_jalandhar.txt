Question1:- What is PHP?
PHP stands for Hypertext Preprocessor. It is a server-side scripting language widely used for web development, enabling the creation of dynamic web pages.
Question2:-How does PHP execute?
PHP code is processed on the server. When a request is made, the server runs the PHP script and sends the resulting HTML to the client’s browser.
Question3:-Is PHP safe to use?
PHP can be secure if best practices are followed, such as input validation and using prepared statements to prevent SQL injection.
Question4:-What are popular PHP frameworks?
Notable PHP frameworks include Laravel, Symfony, CodeIgniter, and Yii, which help streamline the development process with built-in tools and features.
