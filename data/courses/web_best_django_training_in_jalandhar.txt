Question1:- What is Django?
Django is a Python web framework designed for fast, secure, and scalable web application development.
Question2:- What are the benefits of using Django?
Benefits include rapid development, a built-in admin interface, excellent security features, and an active community.
Question3:-How do migrations work in Django?
Migrations track database changes, allowing developers to apply updates easily through command-line tools.
Question4:-Can Django be used for creating REST APIs?
Yes, Django is ideal for REST APIs, especially when combined with the Django REST Framework.
