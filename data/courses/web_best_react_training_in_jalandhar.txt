Question1:-What is the purpose of React?
React is a JavaScript library designed for creating dynamic user interfaces, enabling developers to build interactive web applications with reusable components.
Question2:-How does React optimize rendering with the Virtual DOM?
React uses the Virtual DOM to minimize direct interactions with the actual DOM. It updates the Virtual DOM first, compares it to the previous version, and selectively updates only the changed elements, boosting performance.
Question3:- What are the two main types of components in React?
React primarily consists of functional components, which are simple JavaScript functions returning JSX, and class components, which are ES6 classes that manage state and lifecycle methods.
Question4:-Can you explain the roles of state and props in React?
State is mutable and managed within a component, allowing it to reflect changing data, while props are immutable inputs passed from parent to child components, facilitating data sharing.
